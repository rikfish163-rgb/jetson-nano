# 直行牌与长蓝线：识别后前进，再停车直行

用户确认：识别长蓝线后继续循线前进 0.36 米，到距离后停车回正 1 秒，再直走至少 1.2 米，最后恢复循线。实际保留原直行距离 1.25 米，满足最低要求。

## 当前流程

1. STRAIGHT 路牌缓存，继续循线。
2. 收到前摄长蓝线 junction（检测器当前长度至少 0.35 米）即锁定本次直行事件，不再要求蓝线位于车前 0.36 米，也不再要求近处三帧确认。
3. `BLUE_APPROACH`：从事件锁定位置累计车辆行进距离；有可信白线时循线，短暂缺线保持当前转向和原缺线速度。相机流过期、适用的雷达拦停、红灯和急停仍有效。
4. 行进达到 `straight_blue_advance_m=0.36` 后进入 `BLUE_STOP`，输出速度 0、转向 0，等待 `intersection_wait_s=1` 秒。
5. 停车结束重新记录直行起点，进入 `STRAIGHT_DISTANCE`；保留原右侧纵向蓝线纠偏，前向位移达到 `straight_distance=1.25` 米才回到循线。前面的 0.36 米不计入这 1.25 米。
6. 执行动作期间的新蓝线不重新开始计距，同一条持续可见的蓝线不重复触发；下一次仍需新的路牌和蓝线事件。无牌自动直行在现场命令中用 `blue_default_straight:=false` 关闭。

本次改变直行事件流程；左右转、UTURN、避障和停车原有触发及动作保留。绿牌启动仍采用原起步直行流程。距离来自现有 command_model 指令估算，不是编码器实测。

日志通过 `straight_search.phase`、`approach_travelled_m`、`approach_distance_m`、`stop_until` 和直行 `travelled_m` 区分各阶段，`last_blue_trigger` 记录识别触发时刻。
