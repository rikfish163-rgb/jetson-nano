# 直行至少 1.6 米

- 绿牌启动：从绿牌放行位置起，保持零转向；前向位移达到 1.6 米后，蓝线进入触发范围才交给循线。早于距离门槛的蓝线不提前交接。
- 后续直行：直行任务由蓝线触发时重新记录起点，前向位移不足 1.6 米始终保持零转向，即使已经看到可信车道线。
- 达到距离后，有可信车道线则交给循线；没有可信车道线则继续零转向直行。
- 原有红牌、急停及适用的传感器安全检查保留。恢复循线后的丢线和锥桶误判问题不属于本次修复。

距离使用当前 pose；默认 command_model 是指令积分估计，不是编码器实测距离。车轮打滑、实际车速与标定偏差会影响真实路程。

代码已更新至 Nano 工作区；不自动重启行驶控制。下次重新运行 full.launch 生效，行驶参数无需新增。
