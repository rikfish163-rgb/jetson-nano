## 代码问题与修复

原逻辑左转满 2 s 就立即切右；仅检查右转前 8 cm 的扫掠范围。
存在“8 cm 可通过，但稍后约 20～30 cm 会碰到侧面障碍物”的情况。
先用离线案例 (.45, −.18) m 复现：原逻辑立即发右转；修改后安全继续左转。

- 切换前检查约 0.384 m 的右转车身扫掠，使用全部原始雷达点和原安全余量。
- 若右转扫掠被挡，则继续速度 24 左转；继续左转也必须通过原近距离碰撞与空间可观测检查。
- 每次新扫描重新检查，清空即切右。左转额外时间最多 1.5 s，总左转最多约 3.5 s；右转仍为 6 s。
- 达到限时而右转仍不安全时明确报告 bypass_right_entry_blocked。
- 原侧向绕行上限报告增加 clearance_limit 字段。
- 控制决策发生时缓存阶段与停车依据；日志在独立 telemetry 线程输出。
  即使完整状态因锁忙跳过，停车事件仍能记录为 competition_control_event。
  控制定时器内没有新增控制台输出、文件写入或网络调用。

启动距离与循线代码没有修改。本次使用模型配置的速度和转角；实际速度、舵机角度仍未重新标定。
