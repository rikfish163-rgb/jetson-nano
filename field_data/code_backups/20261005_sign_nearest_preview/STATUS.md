## 限制与保留

- 远近使用检测框面积作为近似，适用于尺寸、朝向相近且完整可见的路牌；没有启用逐牌米制测距。
- “最近”指已检出的候选中的面积最大者；未检出的近牌仍不能参与选择。
- 去重不等于类别确认；小牌的类别分数仍可能波动。高度重叠的真实路牌也可能被去重，因此摆放遮挡会影响检测数量。
- 本次没有运行整车控制器、底盘驱动或执行车辆动作，未验证实车运动中的效果。
- 所有原始文件在 `before/`；审查差异见 `change.patch`，修改前后哈希分别保存在 `before_hashes.txt` 与 `after_hashes.txt`。
- 工作区已有大量与本任务无关的暂存和未暂存内容；本次未提交、暂存、重置或丢弃这些内容。
