# 距离累计与转弯模型修复（2026-10-01）

修改直接写入 Nano `/home/nano/robocup_ws`。未启动车辆节点或发送底盘命令。

## 复现的错误

修复前对实际 ROS 适配器运行四个回归检查，四项均失败：

1. RAW 20、速度模型 .16 m/s、两次控制回调间隔 .20 秒时，应累计 .032 m，
   原代码只累计 .016 m，因为 `dt` 上限为 .10 秒。
2. .10 秒时收到停车反馈，原代码把之前已行驶的 .016 m 一并抹掉。
3. 超过反馈有效期时，原代码把整个控制间隔都按零速处理，而非累计超时前的有效行程。
4. 同一 RAW +22，从 UTURN 切换到 MANEUVER 后，模型轮角从 .365956 rad 变为 .2 rad。

证据在 `adapter_before.txt`。Nano 近期整车日志
`/home/nano/.ros/log/01ad9922-bdda-11f1-a8fc-380025ec2b29/competition_controller-7.log`
也记录了一段 RAW 20 的直行：elapsed_s=7.073246，travelled_m=.987030。
该运行的桥接器日志还有多次 .25 秒中央命令超时；实际有停车的时间不能算成运动。
这不是实测速度或实测路程记录。

## 已完成的修改

- 新增 CommandOdometry，按每条 `/ackermann_cmd` 反馈的源时间戳累计上一条有效命令。
  每条命令最多外推 .25 秒，保留原看门狗时效；控制回调延迟不再截掉有效行程。
  新的停车反馈不会倒过来覆盖之前的运动；延迟到达的停车反馈可纠正先前的外推。
- 将已有 RAW 26 标定移到 `motion/config.yaml`，正常整车的直行、左右转、
  UTURN 位姿和雷达扫掠共用该模型。UTURN 显式实验标定覆盖仍可使用。
- 循线调舵 `max_steer=.2` 与命令尺度 `.03` 保留。
  满舵仍是底盘 RAW ±22，不把 `.2` 当作底盘物理满舵角。
- 转弯几何按左右独立满舵半径计算：前进左 .6784646272 m、右 .9925 m。
  原来两侧使用 `.2` 得到的最小半径约 1.283 m，不符合所选底盘模型。
- 状态输出增加 `motion_model`，控制台同时显示 left_lock/right_lock，便于核对退出判断。
- 直行流程保留：缓存 STRAIGHT → 横向蓝线触发并停车 → 独立直行 1.25 m → 循线。
  途中下一块牌只缓存，不抢占 1.25 m。
