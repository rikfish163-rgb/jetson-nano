## 修改

只修改 `src/robot/obstacle/controller.py`，保留已修复的左转安全延长及碰撞保护。

右转 6 s 改为时间上限，在以下条件连续成立时提前接管：

- 已右转至少 2 s，触发物体在现有位姿模型中已落在后轴后方，超出后悬与安全余量。
- 当前雷达可用；车道新鲜、达到原置信度门限且至少有 3 个实测中心点。
- 观测前向跨度至少 0.20 m；最近中心在 1 m 内、横向偏差不超过 0.18 m。
- 前向方向不超过 30°，相邻段方向变化不超过 20°。
- 连续 3 个不同源时间戳的画面确认，跨度至少 0.15 s；同一帧重复控制周期不会增加票数。

满足条件即清空定时避障，交给普通中心线控制，以弯道速度 16 修正。
成功早退日志原因为 `bypass_visual_lane_handoff`。
6 s 上限及原有短车道恢复分支保留；到上限车道仍不可靠时仍可能等待。
接管后的命令继续通过原始雷达扫掠检查。
