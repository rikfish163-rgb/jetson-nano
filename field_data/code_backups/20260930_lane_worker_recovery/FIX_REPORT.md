# 20260930_194104 停车原因与修复

## 已确认的原因

最后一条车道观测源时间为 1790768484.0839522，状态为 pending_reference。
紧接着图像处理线程在 build_left_boundary_message 中对 None 点读取 y 坐标，
抛出 TypeError 并退出。调试图绘制也存在同样的空点漏洞。
这是上一轮边界参照修复引入的遗漏。

控制器完成其估算的 1.25 m 启动直行后，于 1790768506.811581 报
lane_stream_stale 并下发 [0, 0]。当时车道消息年龄 22.7276 s，
雷达消息年龄 0.3372 s；底盘串口保持打开且命令未超时。
记录位置为命令模型估算，不能视为真实里程测量。

## 本轮改动

- 边界发布先筛选可靠点，再排序；丢线帧仍发布空路径。
- 调试绘图跳过空点，并在缺口处断开连线。
- 定时回调记录单帧异常和堆栈后继续处理下一帧，防止 rospy.Timer 永久退出。
- 保留控制器的消息新鲜度及持续丢线停车保护。
- 启动距离、速度、循线几何及避障参数未修改。
