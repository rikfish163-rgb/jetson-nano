## 修改

- camera/vision.py：保留颜色、长度、实际漆宽校验，合并断段并从相连轮廓恢复直线，不降低长蓝线长度阈值。
- master/state_machine.py、turn/controller.py、camera/observations.py：STRAIGHT 接受横线后，按横线平面与车头位置停车（预留 2 cm）；删除该动作的固定 1 s 对齐加 0.36 m 入场流程。停车后从停车位独立计数 1.25 m，利用右纵向蓝线左侧 0.30 m 的目标继续调整。其他方向动作的入场流程保持原有行为。
- lane/preview.py：支持的圆弧直接使用拟合半径，加上有符号横向偏差与朝向偏差反馈。删除忽略内侧偏差的符号门槛及补偿限幅；非圆弧也允许双向回中。反馈距离取最近可靠中心距离，最低为两个轴距；保留舵量变化率限制。近端偏差大于 4 cm 不进入直道加速。重复使用同一相机帧时，将缓存曲线转换到当前车身坐标，避免继续沿用上一个控制周期的圆心位置与朝向。
- master/controller_node.py：控制台状态增加 pending、蓝线、触发记录、停车与直行阶段，便于核对真实触发过程。
- 更新旧测试的入场假设；旧“出弯至少 raw -8”假设改为验证中心几何与朝向反馈，避免把固定舵量当作中心行驶的证据。
