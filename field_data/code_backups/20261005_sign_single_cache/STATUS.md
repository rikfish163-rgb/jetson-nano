# 路牌单缓存与直行 1.25 米交接验证

用户端日期：2026-10-05。修改已写入 Nano 的 `/home/nano/robocup_ws`。

## 已实现的规则

视野可以显示多个路牌检测框。识别节点按框面积选择最近候选；候选类别分数不足时不改选更远的牌。这是单目图像的距离排序近似，不是实际测距，漏检、尺寸差异、倾斜和遮挡仍会影响选择。

动作牌确认后只能保留一个缓存。等待蓝线时不允许其他牌替换缓存；动作执行期间不允许缓存下一块牌，也不累计下一次确认票数。已经确认的缓存不再因 TTL 过期而提前释放。红牌停车和绿牌放行仍有效。

直行流程为：确认并缓存直行牌 → 蓝线流程完成对齐与入口处理 → 从直行起点前进 1.25 米 → 完成直行并回到循迹 → 用新的观察确认下一块牌 → 下一条有效蓝线触发下一次动作。

保留现有蓝线校准、停止等待和直行参数。直行完成前不接收下一动作；完成后可以接 LEFT、RIGHT、STRAIGHT、UTURN。之前在执行期间提前保存的 `next_direction` 不再转入下一缓存。同一条蓝线保持一次触发；真实清空画面后的新蓝线事件仍可重新触发。

如果绕障前已经有一个路牌缓存，绕障后保留这个原缓存；绕障途中不能新增或替换路牌。绿灯启动直行期间也不新增动作缓存；绿灯前已经确认的掉头牌继续保留。
