# 弯道速度和纠偏修复

最新上传日志包含三次运行。本次分析使用最后一次（sign_capture/20260930_072716_4419）：lane=24、curve=12、straight=12，startup_follow_lane=false。

## 证据与结论

- 弯道巡线实际底盘速度为 12，数秒内舵量只有 -1/-2；随后出现 +10/+8，再转成 -8/-10。这不能仅由速度低解释。
- 实拍中心线回放发现：近处约 6 cm 的横向误差，被旧的“10 cm 对应满舵”比例项放大，抵消右弯前馈，甚至产生左转命令。
- 底盘日志只有指令回显，没有实际轮速或转角测量，因此不能据此断言低速电机/机械死区是原因。

## 修改

- 普通循线弯道及未确认直道时速度改为 16；持续确认居中直道后上限仍为 24。
- 绿牌后 1.25 m 直行门槛和起步速度 12 保留。按用户随后明确的要求，避障左开 2 s、右开 6 s 都改为 24。
- 将独立满舵比例纠偏改成根据近处实际距离计算的圆弧角度纠偏，并乘以 1.25 的反馈增益。原转向限幅、变化速率限制和左右对称性保留。
