# 2026-09-30 巡线与避障回道修复

修复已写入 Nano 的 `/home/nano/robocup_ws`。本轮没有启动车辆。

## 改动

- 同一条当前观测边界通过重叠行的法向距离连续关联，避免初始化把它改名为 RIGHT 后选择旁边的 LEFT。关联只使用当前图像中的点，不复用旧点作为新观测。
- 原参照暂时消失时，不立即接受相邻线。关联历史最多有效 0.5 秒；过期后需要至少三帧、跨度至少 0.1 秒的连续观测，才能建立新左参照。清晰虚线仍提供当前帧的语义证据。
- 左参照向车道内偏移 0.30 m 的距离继续按法向计算，参照位置是车辆中心轴。
- 圆弧、非圆弧和稀疏点统一使用曲率、横向误差、航向误差计算转向。移除强制右转的外弯规则，允许避障回道和弯内偏移时的反向纠偏。
- 非圆弧使用近段曲率；远处出弯直线不会直接稀释近段弯道。原转角变化率限制继续工作。
- 支持弯道的小转向指令至少保留一个底盘舵量单位，避免启动接管时被整数协议舍入为零。
- 新鲜坏帧和空路径最多保持上一条有效指令 0.25 秒；坏帧不能刷新这个期限。持续失效、数据超时和真实障碍仍会停车。
- 调试目标标记改为近处观测参照，以便与当前几何控制对应。
