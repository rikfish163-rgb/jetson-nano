## 修改

- `src/robot/lane/preview.py`：支持可靠圆弧拟合，保留二次曲线回退与逐帧曲率滤波。
  只在实测前向范围内生成 64 点连续参考曲线。
  用曲率和远点几何共同形成前馈，限制近点修正过早抵消受支持的弯道。
  新的直道/相反侧中心仍可释放转向，不增加永久右转锁定。
- `src/robot/obstacle/controller.py`：定时避障若侧点仅挡住原舵角扫掠，
  尝试半舵、直行、反向半舵；每个候选都检查全部原始点、完整安全余量和可观测空间。
  通过时仍用动作速度 24，最长 1.5 s / 0.25 m，随后恢复原阶段。
  替代运动不计入左 2 s / 右 6 s 的满舵时间。
  车身内已有点、扫描过期、未知空间、无安全候选时仍停车。
- 启动脚本及速度策略没有修改：绿牌后先直行 1.25 m（12），弯道 16，确认直道 24。
