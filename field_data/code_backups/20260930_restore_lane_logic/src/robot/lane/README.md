## 原最远点控制与右弯锁

普通循线每帧只取目标路径最靠上的点（车体坐标 x_forward 最大），
按该点到车体中线的横向偏移直接比例控制。鸟瞰图宽 480px，中线 u=240px，
4px/cm；偏差 e=(240-u)/400 米，左正右负。
raw=round(22*clamp(e/lane_lateral_full_scale_m,-1,1))，默认满舵偏差 0.075m。
相对上一次 0.05m 设置，未饱和区增益降低三分之一；偏移 3.75cm 输出约 ±11，7.5cm 达到 ±22。
普通循线不再使用 PurePursuit、前瞻线交点或右转退出的旧左边线参考覆盖。
普通右弯使用满右舵锁：首次看到至少三个点、跨度至少 20 cm、整体朝右超过
10 度且远点右偏至少 3 cm 的一致路径，即进入 `lane_curve_lock`。
锁定期间固定满右舵 raw -22，目标点横偏缩小也不收舵；有效路径的控制诊断为
`right_curve_full_lock`。反向左转目标标记为 `right_curve_hold` 并拒绝，
以 GAP 速度和同一满右舵过渡；空路径也保持满右舵。
拒绝的路径不刷新 GAP 时间或距离，仍保留 4 s / 0.8 m 和真实图像超时停车。
出弯需至少五个不同源帧、持续至少 0.4 s，路径跨度至少 20 cm、直线拟合残差
不超过 2.5 cm。拟合线在后轴前方 0.50 m 处的横偏须不超过 15 cm；
方向可朝右至 8 度、朝左至 25 度，允许车身尚未对齐时所需的出弯左向纠偏。
同时取从最远点起满足至少三点且跨度至少 20 cm 的最短后缀做回归，其方向不得
仍朝右超过 8 度；不存在满足该跨度的后缀时拒绝出弯确认。
不再要求远点全部落在中线 15 cm 内；朝右更明显的路径仍按弯道保护。
确认期间继续满右舵并保持路径有效，确认后恢复原有双向比例控制；
重复控制周期不计作新帧。连续有效出口不会被当成丢线送入 GAP 计时。
起步、路口动作、避障和泊车清除此普通循线约束。录制图的橙圈表示被拒绝的
左侧候选目标，红圈仍只表示实际采用的目标。原始舵量饱和上限仍为 +/-22。
一帧只要有可用前方路径点即可选点；整体置信度不再阻止普通循线选点。
相机过期、无路径处理、障碍停车和专门路口/倒库动作仍由原调度处理。
lookahead 参数保留用于其他调用，但不参与这一普通循线控制律。
