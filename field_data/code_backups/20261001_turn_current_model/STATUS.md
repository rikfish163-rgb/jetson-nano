# 左右转适配当前模型（2026-10-01）

## 完成的修改

- 整车启动脚本启用左转满舵出口接管：入口直行 0.12 m，随后 RAW +22。
  当前 max_steer=0.2 的规划最小半径约 1.283 m；控制退出不再等待这个
  估算圆弧的位置终点。估算转角达到 30 度后，前方车道的近端朝向误差
  小于 20 度、横向误差小于 0.18 m，连续 3 张新图像通过才交给循线。
- 右转保持倒退 0.25 m、满舵找新蓝线、直行 1.25 m 的流程。发送的
  命令舵角不超过当前尺度 0.03（RAW -22）。新蓝线须连续 3 张新图像
  通过已有位置、时效、去重条件，重复控制周期不累加票数。
- 两侧动作阶段使用 action_speed_raw，整车脚本当前默认 20，支持显式
  覆盖为 24 等速度。没有修改普通循线、弯道或 UTURN 的速度参数。
- 日志新增 left_lock 阶段、估算转角和出口诊断；右转日志显示实际限幅
  后的命令舵角及蓝线确认计数。

## 实车边界

max_steer 不是重新测量得到的物理轮角，距离和转角仍为 command_model
估算值。软件验证覆盖指令与状态转换，不能证明实车已贴合车道中心线。
左转的出口识别、右转蓝线连续确认需要现场运行确认。保留现有急停、
红牌、数据失效、动作超时保护；左转超出目标转角 30 度仍无出口时停车。

原始文件备份在 before/，可用于查看这次修改的差异。
