## 修改

`src/robot/motion/controller.py`：仅普通 LANE/GAP、无路口动作、已有右弯锁，
且停车原因是车道流或雷达超时时，停止推进并保持已锁定转向。
同时重置出口确认票数。其他停车原因继续输出速度和转向零。
未放宽图像/雷达时限、GAP 时间/距离上限或更改满舵范围及车速。

修改前文件保存在 `field_data/code_backups/20260930_sensor_stop_steering/`。
