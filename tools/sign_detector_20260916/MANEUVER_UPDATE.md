## 用户在 Nano 启动

启动脚本设置 lane_speed_raw=26、action_speed_raw=28、straight_speed_raw=26，分别覆盖绿牌/循线、普通转弯和直行牌动作。停车速度从 maneuvers.yaml 加载 12，确认目标库底线后停；UTURN 七阶段保持原配置。绿牌启动和后续蓝线直行分别计距 1.25 m。

先在原运行终端 Ctrl+C，然后：

```bash
bash /home/nano/robocup_ws/tools/sign_detector_20260916/run_yolo_vehicle.sh \
  lidar_enabled:=true \
  parking_entry_speed_raw:=12
```

该脚本启用雷达及新绕障。不要使用带 `parking_mode:=reverse_plan` 的旧命令，否则会覆盖新停车模式。代码已写入 Nano 工作区，没有重启用户的运行进程。
