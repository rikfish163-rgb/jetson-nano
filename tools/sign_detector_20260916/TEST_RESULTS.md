# 路牌模型测试集对比（2026-09-16）

## 测试方式

- 1630 张 test 图，1370 个目标，260 张背景。以验证集选出的固定最佳权重测试，没有根据本次 test 成绩调阈值或再选轮次。
- YOLO：yolo_fast/weights/best.pt；D-FINE：dfine_fast/best_stg2.pth，按官方评估流程使用 EMA（如存在）。
- 输入 640，FP32；模型各自既有预处理。两者最终预测都转换到相同 test.json 图像编号，并使用同一 faster_coco_eval COCO 评估器。
- 另固定 confidence >= 0.5、IoU >= 0.5，按图、按类别、置信度从高到低一对一匹配，统计检出、误报、漏检。该阈值未用 test 调优。
- YOLO 原生 save_json 附带的 COCO2017 路径评估不适用本数据集，日志会提示缺少 instances_val2017.json；后续已用真实 test.json 完成共同 COCO 评估。报告中的 common_coco_metrics 才是两者对比依据。

## 结论与限制

- 本测试集上 D-FINE 的综合检测指标高约 0.99 个百分点。YOLO 运行时模型摘要为 7,029,004 参数，D-FINE 训练记录约 30,667,985 参数。Nano 部署优先候选仍为更轻的 YOLOv5s，但参数量不是延迟测试，尚未做 Nano 端到端延迟与兼容性验收，不能说已经证明其适合实时运行。
- 本次只做离线测试，没有替换车上模型或启动车辆。Nano 当前 python3 可导入 TensorRT 7.1.3.0、OpenCV 4.1.1，不能导入 torch、torchvision、onnxruntime；需导出后验证实际部署后端。
- 测试图来自现有采集数据、按拍摄批次划分；框为规则生成并经代表帧抽查，尚非逐帧人工标注。部分开发数据被旧分类器见过；ResNet 的现有 test=100% 不应算独立盲测。
- 这 1370 个目标中，COCO small（标注面积 < 1024 像素²）为 0。当前报告不能证明远处小牌能力，也不覆盖整条赛道的多牌干扰、运动模糊和近牌选择逻辑。
- ResNet 修正版只是裁剪后的分类器；有已知 LEFT→PARK 错误帧修复证据，但与检测器串联后的收益和延迟尚未测试。
- Nano 实际画面回放、不同大小位置、多牌干扰、误报漏检及端到端耗时对比仍待完成。
